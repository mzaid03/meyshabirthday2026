# Meysha Birthday Surprise

An interactive React + Tailwind + Framer Motion experience for Meysha, built as a single-screen journey with mini-games, progress persistence, and a final gratitude reveal.

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - build for production
- `npm run preview` - preview the production build

## Notes

- Progress is stored in `localStorage`.
- Replace the placeholder video slot on the final page with the birthday video.
